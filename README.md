# Reiky Aryanando Pratama — Portfolio

A clear, editorial portfolio for backend and full-stack developer Reiky Aryanando Pratama.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Active experience

- A responsive, two-dimensional portfolio with no WebGL, 3D model, or video runtime.
- A type-led introduction, five layered project windows that rise on hover or focus and can be selected by click, touch, arrows, or keyboard, plus five software case studies.
- Each case study and profile section enters with a short scroll transition, with immediate content for reduced-motion settings.
- OpsFlow, OrderForge, Park Masjid, and JiwaKu descriptions and screenshots sourced from project material; MoneyTrack is described from the supplied CV.
- Full-size screenshot inspection using the native dialog element.
- Keyboard focus, semantic landmarks, lazy-loaded images, and reduced-motion support.
